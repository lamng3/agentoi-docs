Guide 01 · Setup

Getting started

Install AgentOI, inspect an ontology, and query it directly from the terminal.

Install

git clone https://github.com/lamng3/agentoi.git
cd agentoi
./setup.sh
source .venv/bin/activate

For a smaller installation, select only the provider integrations you need:

uv venv --python 3.12
source .venv/bin/activate
uv pip install -e ".[openai,knowledge-graph,dev]"

Configure

cp .env.example .env

Set one model provider and any retrieval services required by your workflow.

PurposeVariables
ModelLLM_MODEL, one provider API key
Ontology lookupBIOPORTAL_API_KEY
Web lookupTAVILY_API_KEY
Google CSE countsGOOGLE_API_KEY, GOOGLE_CSE_CX
Knowledge graphNEO4J_URI, NEO4J_USER, NEO4J_PASSWORD
Thought storageDYNAMO_TABLE, AWS credentials, or AGENTOI_DYNAMO_DISABLED=1

Inspect an ontology

agentoi inspect data/my-ontology.owl
agentoi inspect data/my-ontology.ttl --json

inspect parses local OWL, RDF/XML, Turtle, N-Triples, TriG, TriX, or JSON-LD without loading an embedding or language model.

Search locally

agentoi search data/my-ontology.owl \
  "water quality measurement" --top-k 8

This builds the concept graph and returns the most relevant ontology concepts. The first run may download the configured text embedding model.

Ask questions

# One question
agentoi query data/my-ontology.owl \
  "Which concepts describe freshwater temperature?"

# Interactive terminal session
agentoi chat data/my-ontology.owl

The ontology is parsed and embedded once per command. Interactive mode reuses that graph for every question in the session. Add --refine to apply relation refinement first.

For a local model, set LLM_MODEL=ollama:llama3.1. Hosted models require the corresponding API key.

Run the evaluation pipeline

agentoi run --ontology envo sweet --top_k 10 --eval_alignment
agentoi run --ontology envo sweet --eval_alignment --refine

Catalog-based evaluation output is written under results/runs/.

Select retrieval backends

from agentoi.retrieval import create_vector_index, create_web_search

web = create_web_search("mediawiki")
index = create_vector_index("torch-exact", dimension=768)

Use static or dataset for deterministic offline work. Register project-specific web, ANN, DiskANN, or vector-database adapters through the same public retrieval API.

Optional Jev context selection is separate from retrieval. Install it with uv sync --extra jev, set JEV_API_KEY, and enable AGENTOI_CONTEXT_HARNESS=jev. It starts in shadow mode and fails open to the original shortlist.

Verify

python -m pytest -q
pre-commit run --all-files
