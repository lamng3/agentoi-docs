Getting started

AgentOI requires Python 3.12 and uses uv for reproducible environments.

Install

git clone https://github.com/lamng3/agentoi.git
cd agentoi
./setup.sh
source .venv/bin/activate

For a smaller installation, select only the provider integrations you need:

uv venv --python 3.12
source .venv/bin/activate
uv pip install -e ".[openai,knowledge-graph,dev]"

Configure

cp .env.example .env

Set one model provider and any retrieval services required by your workflow.

PurposeVariables
ModelLLM_MODEL, one provider API key
Ontology lookupBIOPORTAL_API_KEY
Web lookupTAVILY_API_KEY
Knowledge graphNEO4J_URI, NEO4J_USER, NEO4J_PASSWORD
Thought storageDYNAMO_TABLE, AWS credentials, or AGENTOI_DYNAMO_DISABLED=1

Run

agentoi --ontology envo sweet --top_k 10 --eval_alignment

# Rule-based refinement
agentoi --ontology envo sweet --top_k 10 --eval_alignment --refine

Detailed output is written under results/runs/, outside the package and outside Git.

Verify

python -m pytest -q
pre-commit run --all-files
