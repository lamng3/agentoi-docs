Guide 03 · Reproducibility

Experiments

Experiment definitions are JSON. Outputs are generated under results/ and are never committed.

Inspect before running

python -m experiments experiments/configs/quickstart.json --dry-run
python -m experiments experiments/configs/ablations.json --dry-run

Run

# Quick comparison
python -m experiments experiments/configs/quickstart.json

# All maintained ablations
python -m experiments experiments/configs/ablations.json

# One experiment
python -m experiments experiments/configs/ablations.json --select with-uq

Maintained ablations

NamePurpose
baselineEmbedding-based alignment with fixed seed
with-refinementAdds rule-based relation refinement
with-uqAdds formal uncertainty scoring
noise-10Measures robustness under 10% ontology noise

Artifacts

Each experiment writes a combined log, an individual JSON manifest, and a suite manifest containing command, status, timestamps, and duration.

Historical result dumps and one-off comparison scripts are intentionally excluded from this clean repository. Reproduce results from configuration instead.
